# Komari 日报与周报插件

本仓库目前处于开发早期，**尚不是可安装或可运行的 Komari 插件**。完整需求见 [开发需求文档](docs/requirements.md)。

目前仅有不依赖 Komari 的 TypeScript 基础模块和单元测试：累计计数器差值与数据质量、Ping 样本统计、在线时长、周期对比、HTML 转义、状态判定、按时区计算报告周期、简易报告渲染，以及通过注入接口模拟的发送状态和去重。重置或数据缺失时，流量值仅为已观察到的增量，必须标记为不完整，不能当作精确值。

使用 Node.js 24 运行：

```sh
node --test tests/*.test.ts
```

尚未实现插件入口和清单、指标及事件采集、数据持久化、时区调度、报告生成、通知发送、配置与管理界面、打包及 Komari 集成测试。现有单元测试不代表需求已完成，也不验证 MoeJS 兼容性或实际 Telegram 投递。
