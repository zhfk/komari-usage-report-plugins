- 插件配置页底部新增“发送今日日报”，实时统计配置时区今天 00:00 至当前时间，无需选择历史日期。
- 预览、历史补发、测试通知、发送记录与备份统一放入配置页。
- 不再注册独立管理页面，安装包不再包含 HTML 页面文件。
- 修复缺失或改写 Host 时的跨站误拒绝，保留管理员校验，并加入请求令牌与跨站请求保护。
- 历史追补默认关闭，首次启用按计划运行；已保存的配置在升级后保留。
- README 补充 Telegram 通知插件依赖、Bot Token/Chat ID 配置位置和两个插件如何配合。
