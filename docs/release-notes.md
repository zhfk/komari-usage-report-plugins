Komari 日报与周报 v0.1.0

将服务器监控数据整理成定时日报与周报，并通过已配置的 Telegram 通知渠道发送。支持在插件配置页一键发送今天 00:00 至当前时间的日报。

主要功能：

- 节点上传/下载流量、Ping 延迟与丢包、在线率汇总。
- 日报和周报分别启停，自定义发送时间、时区及参与节点。
- 配置页内测试通知、实时发报、历史预览与补发、发送记录及备份。
- 配置事件转发后汇总上下线、性能告警、到期和续费事件。
- 历史追补默认关闭；没有异常时也会按计划生成报告，数据不足会明确提示。

安装前请先启用 Telegram 通知插件，在“通知 → 通知渠道”选择 Telegram，填写 Bot Token、Chat ID 并确认测试消息可以收到。再上传 `komari-daily-weekly-reports-0.1.0.zip`，保存配置并启用，操作面板位于插件配置页下方。

支持 Komari 1.6.1；使用步骤见 README。升级前请备份插件数据，安装新 ZIP 后保留原有配置与记录。
